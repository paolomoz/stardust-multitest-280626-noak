# Improvements — home (and shared across templates, Mode A)

1. **[dated-pattern]** Source home renders as a stack of equal-weight image tiles
   with thin overlaid text; hierarchy between the seasonal hero and secondary
   promos is weak. *Fix:* one full-bleed hero with a left-anchored headline + single
   pill CTA, then a clear promo grid below.
2. **[ia-clutter]** Multiple CTA verbs scattered (Start an order / Order now / Join
   now / Find a store). *Fix:* one canonical primary per surface ("Start an order"
   on hero), others demoted to secondary outline/text links.
3. **[contrast]** Thin white text over bright photos risks AA failure. *Fix:* add a
   legibility scrim gradient behind overlaid hero text.
4. **[cliché]** Product cards are uniform tiny thumbnails. *Fix:* larger circular
   product images at consistent 1:1, mixed-case names, generous grid.
5. **[missed-opportunity]** Brand foam/cream tints unused — pages are flat white.
   *Fix:* alternate white / foam / cream section grounds for rhythm.
